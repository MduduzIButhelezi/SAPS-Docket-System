DIGITAL POLICE CASE & DOCKET SYSTEM - START HERE
================================================

1. Extract the project to a short folder path, for example:
   C:\Projects\SAPS_Docket_System_COMPLETE

2. BACKEND
   - Open SAPS.DocketSystem.sln in Visual Studio.
   - Set SAPS.DocketSystem.Api as Startup Project.
   - Run it.
   - Expected API address: http://localhost:5100

3. FRONTEND
   Open PowerShell:

   cd "C:\Projects\SAPS_Docket_System_COMPLETE\frontend\saps-docket-ui"
   npm install
   npm start

   Open http://localhost:4200

7. IF YOU CHANGED MODELS AND DATABASE ERRORS APPEAR
   Stop backend, delete saps-docket.db, run backend again.
